# Day 11 Reflection

## 1. What did I build today?

Today I built a complete web interface for NexusChat using HTML, CSS and JavaScript. The UI communicates with the FastAPI backend and allows users to chat with indexed documents.

---

## 2. What new features were added?

- Responsive chat interface
- Typing animation
- Session management
- Upload document panel
- Source citations
- Source preview
- Character counter
- Copy response button
- Turn number display

---

## 3. Biggest challenge

The biggest challenge was solving SSL certificate issues while connecting to OpenRouter. I also debugged persistent indexing and document retrieval.

---

## 4. What did I learn?

I learned how to connect a frontend with FastAPI APIs using JavaScript fetch(), display retrieved sources, upload new documents, and manage persistent chat sessions.

---

## 5. What can be improved?

Future improvements include user authentication, drag-and-drop document upload, streaming responses, markdown rendering, and better session management.
